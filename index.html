📌 Discord Webhook einrichten:

Um Nachrichten in Discord zu erhalten:

  1. Gehe zu deinem Discord-Server
  2. Servereinstellungen → Integrationen → Webhooks
  3. Erstelle einen neuen Webhook
  4. Kopiere die Webhook-URL
  5. Füge die URL unten im Code bei WEBHOOK_URL ein
